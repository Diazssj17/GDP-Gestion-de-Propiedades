# GDP - Gestión de Propiedades

Sistema de Gestión de Propiedades (GDP) para la administración integral de bienes inmuebles.

## Descripción
GDP permite gestionar propiedades, propietarios, inquilinos, contratos de arrendamiento, pagos, mantenimiento y reportes.

## Características principales (roadmap)
- [ ] CRUD de propiedades (casas, apartamentos, locales, lotes)
- [ ] Gestión de propietarios e inquilinos
- [ ] Contratos y control de vigencia
- [ ] Control de pagos y morosidad
- [ ] Mantenimiento y tickets
- [ ] Dashboard con indicadores
- [ ] Reportes y exportación

## Stack sugerido
- **Backend:** Python + Flask / Django o Node.js
- **Base de datos:** SQLite (dev) / PostgreSQL (prod)
- **Frontend:** HTML/CSS/JS + Bootstrap
- **Despliegue:** Render / PythonAnywhere

> Puedes cambiar el stack según tu preferencia. Este repo inicia como plantilla agnóstica.
